ZRadio – namestitev

Priključi ESP32-S3 N16R8 s kablom USB (priključek UART) in klikni:

Deluje v Chrome ali Edge na računalniku. Če se namestitev ne začne: drži BOOT, pritisni RST, spusti BOOT.

Po namestitvi
  1. Poveži se na WiFi ZRadio-xxxx, geslo zradio1234.
  2. Odpri http://192.168.4.1 → zavihek Omrežje → vpiši domači WiFi → Shrani → Zaženi znova.
  3. Radio je nato dosegljiv na http://zradio.local.
